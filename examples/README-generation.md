# README是怎样写的

独立代理先读取本仓库dong-kehan/SKILL.md，按需读取writing.md、voice.md和casebook.md，再根据维护者给定的事实卡起草README。模型不联网、不读取其他答卷。

可复用任务：

```text
用 $dong-kehan 为这个开源项目写README。
先讲读者遇到的具体问题和已经能用的东西，尽早给可运行入口，
再交代范围、验证方式与来源。保持自然的问答/文章语气，
不要生成资料检索报告，不编安装命令、用户数量、故事或效果数据。
项目事实：仓库、调用名、功能、已通过测试、数据范围和局限……
```

公开README的开头、主叙事、三类调用示例和段落组织来自这次生成；维护者补入经文档核对的安装命令、真实测试结果和发布链接，没有把未观察到的效果写成提升。
